# COMPLETE — REPORT.md ordering detail

Read this only when the card points here (REPORT.md missing, stale, or hand-written at
COMPLETE). The rule itself (R-complete-002) lives in `stages/complete.md` Step 0.

## Why the report must exist before `surface_run_outputs`

`surface_run_outputs` appends `REPORT.md` as the LAST OUTPUTS row (kind=knowledge), and
the Canvas auto-selects that last row. `build_surface_events` only adds the row when the
file exists at surface time. With no file, the row is silently skipped and the finish
batch auto-opens on a source file instead of the report.

Step 0 sits at the TOP of the card, so a top-to-bottom reader could surface before any
report exists. That is why the card states the prerequisite first.

## Who generates REPORT.md

- `stage-complete --stage deliver` calls `_ensure_report_before_advance`
  (`backend/scripts/artifact_cli.py`). When REPORT.md is missing it runs the
  `run-report` code path in-process and returns `report_generated: true`. It runs both
  before the advance to REFLECT and when DELIVER is the profile's last stage.
- It never touches an existing REPORT.md. A hand-written report is left alone by
  `cmd_run_report`'s own skip guard.
- If generation fails, `stage-complete` warns and its `next_action` starts with
  "REPORT.md gate: run `artifact_cli.py run-report ...`". Do that before surfacing.
- `reflect.md` step 10 runs `run-report --force`, which also inlines the lessons.
- `deliver.md` contains a report TEMPLATE, not a generator call.

## The completion-time refresh (separate from the surface dependency)

INSTRUCTIONS Step 6.1 runs `run-update --status completed` before any report refresh, so
`completed_at` exists and the report's `Duration:` is real rather than `N/A`. The
completion branch regenerates the report itself, but only when it carries
`report_autogenerated`. A hand-written report, or one predating that flag, is left
alone and needs an explicit `run-report --force` if it is stale. This refresh does not
change the surface dependency above: the file must already exist at Step 0.
