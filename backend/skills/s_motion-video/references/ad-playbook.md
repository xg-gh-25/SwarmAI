# Ad playbook

Shared craft for the promotion methods: `product`, `launch`, `feature`, `brand`, `promo`,
`game-drama`. Each method's own structure is in `writing-methods.md` and wins over this
file. Workflow, captions and self-review follow the director's manual and the contract.
Rules written in a style file win over this file. English word counts use chars x 0.58
(contract speech rates).

---

## 1. Fix one promise first

Answer the ad six questions (audience, pain or desire, promise, product's role, proof,
action) in `director.md` section 2.

- The film is built around the promise, not a feature list. A website is ordered by
  information; an ad is ordered by emotion. Material may be shuffled, merged or dropped.
- Value before proof: the promise is said by scene 2 at the latest; features, demos and data
  after it are its proof.
- Self-check: delete every proof scene, the rest still says why to buy. Delete the value
  scenes; if the film still looks complete, it is only a feature tour.

---

## 2. Pick one storyline

| Storyline | Use when | Scene order |
|---|---|---|
| Pain -> amplify -> solve | the pain is clear and urgent (workflow, efficiency) | hook -> pain -> amplify the cost -> product enters -> demo or proof -> action |
| Before / after | a new way replaces an old one | before -> tease "now" -> product -> step 1 -> step 2 -> surprising result -> action |
| Demo loop | the interface is self-explanatory; best seen running | a problem -> product reveal -> demo 1 -> demo 2 -> build trust -> action |
| Feature-benefit chain | many features, or it sells by taste or identity | category hook -> feature -> benefit -> feature -> benefit -> climax -> action |
| Future scene | selling a new way of doing or a new category | imagine -> name the product -> the pain disappears -> how it works -> result -> action |

With many features, whatever the storyline, keep the feature -> benefit rhythm: translate
each feature into what the viewer gains; never stack features one after another.

## 3. Skeletons by ad type (quick reference)

Details are in each method (`writing-methods.md`). An app demo belongs to `product`.

| Type | Storyline | Skeleton | Key shot |
|---|---|---|---|
| Launch | feature-benefit chain or future scene | suspense or spectacle hook -> hero reveal (name + one-line positioning) -> 2-3 selling points -> proof (specs, data) -> price and availability -> end card | `hero-reveal`: mask reveal plus a light push, the most ceremonial moment |
| Feature update | before/after or pain -> amplify -> solve | the old way's trouble -> "now" -> 2-3 step demo of the new feature -> result (time saved, fewer steps) -> action ("update to the latest version") | `before-after`: the same task done two ways |
| Brand | future scene or feature-benefit chain | a moment the audience recognises -> value proposition -> three proofs (scenes, people, numbers) -> slogan end card | `anchored-rotation`: brand name fixed, people and scenes rotate beside it |
| App demo | demo loop | one concrete problem -> first look at the app -> core flow 2-4 steps -> result -> more scenarios -> download | `ui-walkthrough`: use the user's screenshots, one operation per scene |
| Promotion | short pain -> amplify -> solve | offer hook (price, deadline) -> product hero -> 1-2 selling points -> price reveal (original struck) -> deadline plus action | `number-flip` / `price-reveal`: digits stop one by one |

- An interface demo is usually a run of 3 or more scenes (input -> response -> result ->
  benefit) on one persistent interface; never a single scene.
- Product UI: prefer the user's screenshots. If you must redraw, draw only the parts
  mentioned, copy the screenshot's layout and colours, and add no feature the product lacks.
- Music: launches and tech products = tech; consumer goods and promotions = bright; premium
  brands = calm or none.
- Voice: launches and tech = formal broadcast or sincere friendly chat; consumer goods and
  product recommendations = friendly chat; young or funny = comedic; children's products =
  cartoon.

## 4. The first 3 seconds

| Time | Must be true |
|---|---|
| Frame 0 | Content is already on screen (background plus one subject); never blank or a flat colour |
| 0.1-0.3 s | The first motion starts |
| by 1.5 s | The hook keyword is spoken and appears as big text or in the picture |
| by 3 s | The viewer knows "what this has to do with me" |

- Never open with a logo sting, a company introduction, "Hello everyone" (大家好) or "Today
  I'd like to introduce" (今天给大家介绍). If the brand must appear early, keep a small logo
  in a corner.
- The hook states the result the viewer gets (what they gain, what they skip), not a
  feature name, model number or spec list. Use a number only when it is the stakes
  ("save 40% of your time"), never as a list ("23 upgrades").
- Hook types:
  - hit the pain: 每天加班改表格？(Working late fixing spreadsheets every day?)
  - counter-intuitive: 最贵的不是会员，是你的时间 (The most expensive thing isn't the
    membership, it's your time)
  - shock number
  - question
  - put yourself in the scene: 你是不是也……(Are you also the one who ...)
  - before/after
  - product spectacle: show the most beautiful shot first
  - offer hook (promotions)
  Do not open every ad with a number.
- First-scene narration 12-25 Chinese chars (about 7-14 English words). Once the hook
  stands, name the product.
- Feeds are often watched on mute, so the hook must work on screen: the key question or
  number appears as big text, not only in the captions.

## 5. Rhythm and density

Budget: narration ~ rate x (length - 0.4 s x scenes), contract rate and padding; land a
little under the counts below.

| Length | Scenes | Narration zh chars | en words | Recommended structure |
|---|---|---|---|---|
| 15 s | 2-3 | about 62-64 | about 36 | hook (3-5 s) -> one selling point or hero reveal (6-7 s) -> end card plus action (4-5 s) |
| 30 s | 3-5 | about 126-130 | about 73-75 | hook -> product reveal -> 1-2 selling points -> proof -> end card |
| 60 s | 5-8 | about 255-260 | about 148-150 | full storyline: 2-3 selling points, one proof scene, one end card |

- **15 s carries one selling point.** Hook, three selling points and an action in 15 s is
  only noise.
- Scene length usually 5-10 s; a short ad's hook may be 3-5 s (unless the style says
  otherwise). Inside a scene a new event every 1.5-3 s; after an element settles, hold at
  least 1 s.
- Before writing, pick one or two reference ads for this category and style; note what to
  learn (structure, rhythm, shot grammar, colour logic) and what not to take (logos, fonts,
  specific shots, melodies).
- Set a rhythm pattern for the film before you start, e.g. fast-fast-slow-fast-stop. The
  slowest scene is at least 3x slower than the fastest. The heaviest line of narration is the
  energy peak.
- Plan one **stop**: a scene with one sentence and an almost still picture, usually right
  before the hero reveal or the end card (keep one slow drift: never fully still for more
  than the contract allows).
- **Full-screen impacts** (a full colour block sweeping the frame, a fly-through move, a big
  push) 2-3 per film: one at the hero reveal, one at the end card, at most one more. At
  least 8 s between two of them.
- Vary the layout between selling points; at least three layouts in the film. The same
  selling-point structure (push in -> result -> label) may repeat three times to make a
  rhythm, but with a different subject each time.

## 6. Copy: narration and on-screen text

**Narration**
- Per scene 15-40 Chinese chars (about 9-23 words); one sentence at most 20 chars (about 12
  words). Between commas keep within one caption line (contract line length).
- Say "you", start with verbs, say concrete things: "一句话，出一支视频" (one sentence, one
  video) beats "智能高效的视频创作解决方案" (an intelligent, efficient video creation
  solution).
- Translate features into benefits:

| Feature | Benefit |
|---|---|
| 支持 65W 快充 (65 W fast charging) | 充 10 分钟，用一下午 (charge 10 minutes, use it all afternoon) |
| 内置 200 套模板 (200 built-in templates) | 一打开就有现成的版式 (a ready layout the moment you open it) |
| AI 自动剪辑 (AI auto-editing) | 素材扔进去，成片自己出来 (drop the clips in, the film comes out) |

- Three selling points in parallel form, rhythm short-short-long; the last one weighs most.
- Say the brand name at least twice: once at the reveal, once at the end card.
- No empty words: 赋能 (empower), 一站式 (one-stop), 颠覆 (disrupt), 重新定义 (redefine),
  极致体验 (ultimate experience), 开启新篇章 (open a new chapter), 无缝衔接 (seamless).
- No superlatives: 最 (most), 第一 (first), 唯一 (only), 顶级 (top), 首个 (first ever),
  国家级 (national-level), 100%, unless the user gave a verifiable source. Performance
  numbers state their test conditions in a small footnote in a corner, never in the caption
  band.
- Offers and guarantees ("7 天无理由" 7-day no-reason returns, "限时" limited time) only if
  the user gave them. Never invent.
- For more energy, choose a livelier voice; a comedic voice works best with one or two
  interjections per film.

**On-screen text**
- On-screen text is not the narration. Captions show the whole sentence; the screen shows
  only selling-point words, numbers, prices and the slogan.
- At most 8 Chinese chars per line (about 4 English words), at most two lines. Arabic digits;
  units one size smaller.
- Appears when spoken (keyword time from `words.json`) and stays visible at least Chinese
  chars / 4.5 + other chars / 15 + 1.5 s.
- Price: the final price is the biggest text; the original price struck through beside it;
  the currency sign (¥, $) and decimals one size smaller.

## 8. End card and call to action

- **One action only**, written as verb + object + where: download now; search "brand";
  scan to claim; tap the link below; book now (立即下载、搜索「品牌名」、扫码领取、点击下方链接、
  现在预约). Never two or three actions side by side.
- At most 4 elements: logo, one slogan, the action (URL, search term or QR code, only ones
  the user gave), and optionally a price or date.
- **Build, then hold**: the end card is fully built within the first 40% of the last scene,
  then stays completely still to the end; at most one tiny hint motion (e.g. an arrow
  nudging forward every two beats). The voice says the call to action during the still
  part. The complete end card is visible at least 2-2.5 s. (This hold is the contract's
  end-card exception to the stillness limit.)
- Logo: the user's original file, shape and ratio unchanged. The symbol first; about 0.2 s
  after it settles, the wordmark.
- QR code: large (at least 20% of the frame's short side), with a quiet margin, never in the
  caption band or the portrait platform-button zone.
- Last-scene narration 15-25 Chinese chars (about 9-14 words), shaped as brand + one
  promise + one action, e.g. "轻记，想到就记下。去应用商店搜轻记。" (Qingji: note it the moment
  you think of it. Search Qingji in the app store.)
- The end card never flashes past, and never adds a new selling point.

## 9. Aspect ratio and platform

| Ratio | Typical place | Layout |
|---|---|---|
| 16:9 | website, video sites, keynote screens, landscape store screens | left/right split allowed (picture 60%, text 40%); caption band at the bottom ~16% |
| 9:16 | short-video and social feeds | stack vertically; content between 7.5% and 67% of height (top for the platform bar; from ~70% down are captions and platform buttons); like/comment buttons on the lower right, keep ~12% from the right edge; visual centre at 37-40% of height |
| 1:1 | social feeds, e-commerce main video | side by side only for two small elements, else stack; small usable centre, fewer words |
| 4:5 | to take a bit more height in a feed | like 1:1 with one more row |

- Design for the chosen ratio from the storyboard on; never build landscape and crop. Size
  type by the short side; portrait lines hold fewer words, at most 8 chars (4 words).
- Portrait ads run faster: 15 s = 2-3 scenes, one thing per scene, product or result in the
  first scene, no warm-up.

## 10. Symptoms and fixes

| Symptom | Fix |
|---|---|
| Logo or company intro opens; 3 s with no information | make scene 1 a hook; logo in a corner or saved for the end card |
| A string of feature names nobody remembers | keep 1-3 selling points, each translated to a benefit |
| Every selling point in the same layout | use other ad shot types; at least three layouts |
| Three selling points crammed into 15 s | hook + one selling point + action |
| Big claims, no proof | give each promise a demo or a sourced number |
| Vague call to action, or several | keep one, as verb + object + where |
| End card flashes and is gone | build it within the first 40% of the last scene, then hold |
| On-screen text repeats the captions | screen shows only keywords, numbers, prices |
| Portrait film reuses the landscape layout | stack vertically; avoid the top bar and right-side buttons |
| Bouncing, flashing, everything moving; looks cheap | mostly smooth deceleration; one moving protagonist at a time |
| Superlatives or invented offers | delete; keep only what the user gave and can be verified |
| Redrawn UI doesn't look like the product | use the user's screenshots; if redrawing, copy their layout and colours |
| Same speed from start to end | set the rhythm pattern, add a stop, slow down before the climax |
| No shot anyone remembers | make the hero reveal the biggest, most style-typical action of the film (mask reveal, light band sweep, product growing out of its material), at least 1 s, slower before and after |
| Elements slide in and out like slides | give each move anticipation and follow-through (shrink slightly then pop; after landing a small settle or slow push); overlap neighbouring entrances |
