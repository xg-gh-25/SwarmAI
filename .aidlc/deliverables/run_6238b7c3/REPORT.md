## TL;DR
**解决了什么问题**
- 原来：The deterministic Gate-2 flow from step 3a existed behind a flag, but no run had used it: the DELIVER card described only the legacy steps, and the validator still judged a deterministic DELIVER by model verdicts (unresolved finding, Red Team, meta-review, convergence), so its push_ready could never be true.
- 现在：A run created with --convergence deterministic is sent to the gate2-next loop by the card, both validator doors and the Red Team trigger follow the run's flow through one predicate, the DELIVER artifact's findings are the ledger's (with the expert's severity), and the roster stays frozen after the first fix so a DELIVER re-entry cannot dead-end the ledger. The default stays legacy.

**怎么做的**
- pipeline_validator.model_verdicts_decide is the one definition of the mode; validate_artifact_data and _check_depth take convergence=
- _project_ledger_review writes adversarial_review from gate2-next at both DELIVER doors (stage-complete, publish)
- _gate2_round_roster freezes the Gate-2 roster from the protected hand-out ledger once a fix exists
- ref/deliver/gate2-deterministic.md describes the loop; deliver.md points to it

## 3. Design & Approach
**Research Findings (THINK):**
- Correction to EVALUATE's framing: a deterministic run CAN finish DELIVER today. stage-complete turns every gate error that is not structural (_NEVER_DEGRADE, artifact_cli.py:10215) into a degraded record (_degrade_gate_errors :10227), and run-update --status completed waives validator errors on degraded stages (artifact_cli.py ~:3186-3192). So the model-verdict checks do not block; they set push_ready=false and fill REPORT section 10 with legacy errors
- So the real defect is the push_ready signal and the record, not landing: under convergence=deterministic a run whose every finding is proven still gets push_ready=false, because the validator reports meta_review missing, convergence missing and any unresolved adversarial finding (pipeline_validator.py:2496, :2520, :2553-2575, :3182, :3205), and artifact_cli adds the Red Team trigger (:10353). The design (section 2.5, D6) says push_ready is lowered by not-proven ledger rows and tests, nothing else
- Both validator doors (validate_artifact_data :2338 at publish, _check_depth :3109 at completion) take no run state; the completion caller (pipeline_validator.validate, :4419) has the run dict in hand (run.get('created_at')), so the convergence mode can be passed at both doors without a new lookup
- The Red Team trigger has one predicate in artifact_cli, _red_team_required_now (:4607); it feeds stage-complete (:10353) and the required_experts injection (:904, :3722, :5665). One check there covers C4 and C5
- _derive_stage_fields (artifact_cli.py:9979) runs before validation and already fills derived DELIVER fields; it is the place for the CLI to write adversarial_review from the gate2-next ledger (_gate2_next_view :12208)
- Flipping the run-create default changes only new runs: _deterministic() (artifact_cli.py:12100) is true only for an explicit 'deterministic', so existing and fixture runs without the key stay legacy
- stages/deliver.md has no deterministic branch; it is the card an agent reads at DELIVER (37 lines)

**Alternatives Evaluated:**
- QUALITY — effort: M

**Chosen Approach:** Approach QUALITY from THINK. One predicate pipeline_validator.model_verdicts_decide(convergence) -> bool (True unless 'deterministic'). validate_artifact_data and _check_depth take a keyword convergence=None (None keeps today's behaviour for every existing caller) and skip the five model-verdict checks when the predicate is False. Callers pass the run's mode: artifact_cli._validate_stage_candidate (stage-complete), the legacy publish path (cmd_publish, run.json already read there), and pipeline_validator.validate (completion, run dict already loaded). artifact_cli._red_team_required_now returns False for a deterministic run. _derive_stage_fields, for deliver in a deterministic run, replaces adversarial_review with a projection of _gate2_next_view's ledger. cmd_run_create writes convergence=deterministic unless --convergence legacy. deliver.md gets a one-line pointer to a new ref card stages/ref/deliver/gate2-deterministic.md.
