**解决了什么问题**
- 原来：Worktree mode was off unless config.json said on, so a fresh install ran every pipeline run on the shared checkout with the legacy Gate-2, and only this machine had it switched on.
- 现在：Worktree mode is on unless config.json says off. A fresh install writes on; an install that already has off keeps it. A run that cannot get a worktree still falls back to the shared checkout.

**怎么做的**
- mode_enabled returns True unless the config says off (or JSON false)
- DEFAULT_CONFIG writes on
- conftest pins tests to off, the mode they all ran under
