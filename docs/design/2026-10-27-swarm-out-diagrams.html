架构：东西在哪、什么跨过边界

三块地方：本机 Host 负责澄清、派发和验收导入；S3 只放按 Hive 名字分开的包和记录；Hive 只执行。控制只由 Host 发起，代码和经验只在 Host 上、核对之后才进 main 和 Brain。

一个大脑，一个写入者。 Hive 读每个 Run 的只读 DDD 快照，认知写入全部关闭，REFLECT 只导出；经验由本机判官写进 Brain。
Hive 之间互相隔离。 briefs/ 只有目标 Hive 能读，records/ 只有那台 Hive 能写、不能删、不能覆盖；参考实例读不到任何包和记录。
进 main 的就是审过测过的 tree。 本机 main 没动就 ff-only 合入；动过就派 follow-up Run 在新 base 上重测，不在本机悄悄 rebase。

流程：一个 Run 从说需求到合入 main

从左到右是五个参与方，从上到下是时间。灰底横条是阶段；琥珀色箭头是 XG 自己的动作，只出现在说需求、点派出去和回答问题三处。
