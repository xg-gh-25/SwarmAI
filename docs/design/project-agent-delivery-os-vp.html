Organization North Star

提升自治交付率，同时不牺牲质量、安全和必要的人类判断。

Autonomous Delivery Rate
↑ Measurable & Improving
ADR = A / E
E: 执行前在 Triage 固定、已准入 Project Agent Delivery 的 Intent revisions。
A: 完成可信交付、Trace 完整、Isolation/Quality PASS，且无 preventable intervention。
始终留在 E、不进入 A：失败、abandoned、system-cancelled、Trace/Isolation/Quality UNKNOWN 或 BLOCK。
排除但单独报告：duplicate/test、准入前 unsupported、执行前 user-withdrawn、superseded，以及尚无 workload contract 的 standalone research/no-code。
Preventable：question、correction、manual routing/retry、operational rescue、unnecessary approval、manual code fix、takeover。Required judgment 保持 neutral。
Isolation stays green Quality stays green Required judgment is neutral
